How much to say

Read this before you set off

  • This is a prototype. It has never been validated on a ride. Treat every callout as possibly wrong.
  • It describes the road — it is not telling you to go faster. Ride within your sight lines and the law.
  • Callouts can be late, missing, or about the wrong corner, especially where GPS is poor.
  • Start it while stopped. Don't look at or touch the screen while moving.

Keep this tab open. Once loaded it needs GPS but no signal, so it works in dead zones.
